# 2026년 8월 31일 개발 로그

## 학식 메뉴별 계정 평가

- 진리관과 교직원 식당의 비어 있지 않은 모든 메뉴에 좋아요·싫어요 평가를 추가했다.
- 밥, 김치, 국, 반찬을 포함해 크롤링되는 모든 메뉴를 동일한 평가 대상으로 처리한다.
- 평가는 로그인 사용자만 저장하며, 비로그인 사용자가 누르면 카카오 로그인 안내 바텀시트를 표시한다.
- 로그인 뒤 선택한 식당과 요일로 돌아오도록 `next` 경로에 현재 학식 맥락을 보존한다.
- 한 사용자는 같은 메뉴 제공 회차에 반응 하나만 남길 수 있다.
- 선택한 반응을 다시 누르면 취소되고, 반대 반응을 누르면 기존 반응이 변경된다.
- 투표 요청 중에는 같은 메뉴의 중복 요청을 막고, 저장 결과는 서버가 반환한 최신 집계로 교체한다.

## 평가 가능 기간과 사용자 안내

- 한국 시간 기준 현재 주의 월요일부터 오늘까지 나온 메뉴만 평가할 수 있게 했다.
- 오늘보다 뒤인 메뉴를 누르면 `목요일부터 평가할 수 있어요`처럼 실제 요일을 안내하는 토스트를 표시한다.
- 토요일과 일요일에는 같은 주의 월요일부터 금요일 메뉴를 모두 평가할 수 있다.
- 지난주와 다음 주 메뉴는 평가할 수 없도록 서버와 화면 양쪽에서 검증한다.
- 미래 메뉴 버튼을 비활성화하지 않고 눌렀을 때 이유를 알려 주어 사용자가 동작 불가 원인을 알 수 있게 했다.

## 메뉴 통계와 화면 구성

- 각 메뉴 행에 현재 제공 회차의 좋아요·싫어요 수와 사용자의 선택 상태를 표시한다.
- 같은 식당에서 같은 이름의 메뉴가 다시 등장하고 누적 평가가 5개 이상이면 `누적 18명 · 72%가 좋아했어요` 형식의 짧은 통계를 표시한다.
- 식당이 다른 같은 이름의 메뉴는 서로 합산하지 않는다.
- 학식 독립 페이지와 메인 지도 학식 바텀시트가 같은 GB1 메뉴 평가 행을 사용하도록 통일했다.
- 상시매장 메뉴 평가는 이번 범위에서 제외하고 기존 메뉴명과 가격만 유지했다.

## 데이터베이스와 회원 탈퇴

- 기존 익명 식별자 `voter_hash`를 제거하고 투표를 `users.id` 외래키에 연결했다.
- `메뉴 제공 회차 + 사용자` 유일 인덱스로 계정당 한 번만 평가되도록 보장했다.
- 회원 탈퇴 시 해당 사용자의 메뉴 평가가 외래키 `ON DELETE CASCADE`로 함께 삭제되도록 변경했다.
- 기존 익명 평가 3개를 삭제하고 새 계정형 스키마를 운영 DB에 적용했다.
- 기존에 평가 불가였던 진리관·교직원 메뉴 제공 회차 147개를 평가 가능 상태로 전환했다.
- 운영 DB에서 `user_id` 컬럼, 계정 유일 인덱스, 사용자 삭제 CASCADE, 익명 평가 0개를 직접 확인했다.
