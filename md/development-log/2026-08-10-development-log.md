# 2026-08-10 개발 로그

## 바텀시트 상호작용 개선

- 홈, 캠퍼스 구역, 학식, 셔틀 바텀시트를 사용자가 직접 높이 조절할 수 있게 했다.
- 바텀시트 높이는 `최소`, `중간`, `최대` 3단계로 구성했다.
  - 390×844 화면 기준 최소 160px
  - 중간 385.5px
  - 최대 약 630.3px
- 손잡이를 드래그하면 이동 높이를 즉시 반영하고, 놓는 위치와 스와이프 속도에 따라 가까운 단계로 스냅한다.
- 손잡이 탭으로 높이를 순환할 수 있게 했고, 키보드의 위·아래 방향키와 `Home`, `End` 키도 지원한다.
- 마우스와 모바일 터치를 함께 처리하도록 Pointer Events와 포인터 캡처를 사용했다.
- 바텀시트가 최대 높이여도 지도 상단 약 1/6 영역은 남도록 유지했다.

## 하단 내비게이션 수정

- 바텀시트와 하단 내비게이션 사이에 발생하던 3px 간격을 제거했다.
- 안전 영역을 포함한 실제 내비게이션 높이를 `--bottom-navigation-height` 공통 CSS 변수로 정의해 두 요소가 동일한 기준을 사용하게 했다.
- 선택된 하단 내비게이션 항목에 `text-brand` 클래스가 있어도 전역 링크 색상 규칙에 덮이던 원인을 수정했다.
- 홈, 학식, 셔틀 활성 항목이 크림슨 `#a61942`로 표시되는 것을 확인했다.

  - 느린 이동의 최근접 단계 스냅

## 건물 콘텐츠 방향 검토

- 건물을 선택하면 최대 높이 바텀시트에서 `지금, 공공정책관`과 같은 제목을 보여주는 방향을 검토했다.
- 건물 콘텐츠는 사용자 글·사진과 당일 행사·이벤트 두 영역으로 구성한다.
- 건물 탐색과 요약은 바텀시트에 유지하고, 글쓰기·게시물 상세·행사 상세·사진 전체 보기는 별도 페이지로 분리하는 혼합형을 우선안으로 정리했다.
- 건물 선택 시에만 최신 데이터 일부를 지연 로딩하고, 전체 목록은 커서 기반 페이지네이션으로 불러오는 방식을 권장한다.
- 사진 원본은 Neon DB가 아니라 Cloudflare R2에 저장하고, Neon에는 게시물과 이미지 메타데이터만 저장하는 방향을 권장한다.
- 실제 구현 전 작성자 표시 방식, 신고·삭제·차단 정책, 사진 개수와 용량 제한을 확정해야 한다.

## 검증

- `npm test`: 18개 테스트 파일, 56개 테스트 통과
- `npm run check`: Svelte 오류 0건, 경고 0건
- 390×844 모바일 화면에서 바텀시트 높이 160px, 385.5px, 약 630.3px을 확인했다.
- 홈·학식·셔틀 활성 색상이 크림슨으로 표시되고, 바텀시트와 내비게이션 간격이 0px인 것을 확인했다.
- 실행 중인 개발서버의 Cloudflare `workerd`가 `.svelte-kit/cloudflare`를 점유해 현재 작업 폴더의 빌드 정리 단계에서 `EBUSY`가 발생했다.
- 동일 소스를 임시 격리 폴더에서 빌드해 Cloudflare 어댑터까지 정상 완료되는 것을 확인했다.
- 실제 휴대폰에서는 손가락 드래그와 바텀시트 내부 목록 스크롤이 충돌하지 않는지 추가 확인이 필요하다.
