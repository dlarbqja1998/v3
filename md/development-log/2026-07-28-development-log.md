# 2026-07-28 개발 로그

## 변경 사항

- v3 로그인 기획에 맞춰 카카오 OAuth 콜백 라우트를 추가했다.
- 카카오 사용자 ID 기준으로 기존 사용자를 조회하고, 없으면 `users` 테이블에 신규 사용자를 생성하도록 했다.
- 로그인 성공 후 서명된 `session_id` 쿠키를 발급하고, 서버 훅에서 세션 사용자를 `locals.user`로 주입하도록 했다.
- 온보딩을 완료하지 않은 로그인 사용자는 `/register`로 이동시키는 보호 흐름을 추가했다.
- `/login` 화면과 서버 로드를 추가해 카카오 로그인 URL을 생성하고, 관리자 로그인 액션을 처리하도록 했다.
- 관리자 로그인은 환경변수 기반 ID와 비밀번호를 사용하고, 실패 횟수 제한과 잠금 시간을 두었다.
- `/register`를 닉네임, 단과대, 학과, 학번, 성별을 받는 하이브리드 온보딩 화면으로 구성했다.
- 닉네임 길이와 필수값, 단과대·학과·학번·성별 선택값을 검증하는 도메인 로직과 테스트를 추가했다.
- `users` 테이블 스키마와 Drizzle 마이그레이션을 추가했다.
- 홈 화면 상단에 로그인 상태를 반영해 비로그인 사용자는 로그인 버튼, 로그인 사용자는 닉네임 또는 관리자 표시가 보이도록 했다.

## 운영 메모

- 개발 단계의 카카오 Redirect URI는 `http://localhost:5173/auth/callback/kakao`를 사용한다.
- 카카오 Developers의 Redirect URI와 앱이 보내는 `redirect_uri`는 프로토콜, 도메인, 포트, 경로가 완전히 일치해야 한다.
- 로컬 개발용 `AUTH_URL`은 `http://localhost:5173`로 맞춰야 KOE006 오류가 나지 않는다.
- 실제 DB에 `users` 테이블을 만들려면 마이그레이션 반영 또는 `npm run db:push` 실행이 필요하다.
- `.env`는 Git 추적 대상이 아니므로 커밋에 포함하지 않았다.
