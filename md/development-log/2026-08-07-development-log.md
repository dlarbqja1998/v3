# 2026-08-07 개발 로그

## 캠퍼스 구역 지도

- 건물, 광장, 주요 지점 25개의 중심 좌표와 폴리곤을 `campus_spots` 테이블로 이관했다.
- `db:push`가 관계없는 외래키 변경을 제안해 사용하지 않고, 전용 스크립트로 `campus_spots` 테이블만 생성했다.
- 일반 사용자는 핀 탭을 열 때만 캠퍼스 구역 API를 요청한다. Cloudflare KV 캐시를 우선 읽고, 캐시가 없을 때만 Neon DB를 조회한다.
- 구역을 선택하면 중심 핀이 지도 상단 1/6 영역에 오도록 이동하고, 바텀시트에 구역 정보를 표시한다.

## 관리자 경계 편집기

- `/admin/boundary-editor`를 추가했다. 관리자 로그인 사용자만 접근할 수 있다.
- 지도 클릭으로 꼭짓점을 추가하고, 드래그로 이동하며, 우클릭으로 삭제할 수 있다.
- 새 꼭짓점은 배열 마지막이 아니라 클릭 지점과 가장 가까운 기존 경계선 사이에 삽입되도록 수정했다.
- 네이버 지도 SDK가 컨테이너 배치 속성을 덮어써 지도가 0px 높이로 접히던 문제를 래퍼 구조로 해결했다.
- 저장 시 바운더리와 다시 계산한 중심 좌표를 DB에 반영하고, 공개 지도 캐시를 함께 갱신한다.
- 편집기에는 메인으로 돌아가는 나가기 링크를 추가했고, 마이 탭에는 관리자에게만 핀 수정하기 메뉴를 노출했다.

## 배포·초기화 명령

```powershell
npm run db:campus-spots:apply
npm run db:campus-spots:seed
```

## 메인 지도 경험 및 내비게이션 개편
- 메인 색상을 화이트와 크림슨 중심으로 정리하고, 상단에 추후 브랜드 PNG로 교체할 아이콘 자리를 추가한다.
- 하단 내비게이션을 `홈`, `학식`, `셔틀`, `오늘`, `마이` 5개 탭으로 교체하고, `오늘`의 행사·이벤트 화면을 빈 상태로 먼저 연결한다.
- 홈 상단의 구역·검색·카테고리 필터와 배경 그라데이션을 제거해 앱 아이콘, 서비스명, 로그인만 남긴다.
- 캠퍼스 바운더리는 홈에서 기본으로 표시한다. 초기에는 중앙 원을 표시하지 않고, 바운더리 클릭 시에만 선택한 건물 중앙에 핀을 표시한다.
- 선택된 바운더리는 건물 중심이 화면 상단 1/6 영역의 중앙에 오도록 이동하며, 건물명과 설명을 포함한 바텀시트를 연다.
- 홈 진입과 홈 탭 클릭 시 신정문을 화면 정중앙에 두고 줌 레벨 17로 복귀한다.
- 네이버 지도 폴리곤의 기본 클릭 비허용 옵션을 명시적으로 활성화해 바운더리 선택이 동작하도록 수정한다.
- 자동 지도 이동 중 사용자가 마우스·터치·드래그를 시작하면 `map.stop()`으로 진행 중인 애니메이션을 취소해 사용자 조작이 우선되도록 한다.
