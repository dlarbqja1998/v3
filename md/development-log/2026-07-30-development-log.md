# 2026-07-30 개발 로그

## 변경 사항

- 마이페이지 기획과 하단 네비게이션 기획을 바탕으로 `/my` 페이지를 추가했다.
- `/my`에서 닉네임, 단과대, 학과, 학번, 성별, 로그인 방식을 확인할 수 있게 했다.
- `/my`에 `내 정보 수정하기`와 `로그아웃` 액션을 추가했다.
- `/my/edit` 페이지를 추가해 기존 온보딩 검증을 재사용하면서 사용자 기본 정보를 수정할 수 있게 했다.
- 하단 네비게이션을 공통 컴포넌트로 추가하고 `학식`, `셔틀`, `핀`, `마이` 항목을 구성했다.
- 홈 화면에서 하단 네비게이션의 `학식`, `셔틀`, `핀`을 누르면 각각 학식 바텀시트, 셔틀 바텀시트, 핀 준비 중 바텀시트로 전환되게 했다.
- 지도 핀 포커스 계산을 별도 모듈로 분리하고, 바텀시트가 열린 상태에서 상단 1/6 영역 중앙에 핀이 오도록 조정했다.
- 조치원역 후편 셔틀 정류장 핀이 바텀시트 뒤로 밀리지 않도록 지도 중심 남쪽 경계를 보정했다.
- 마이페이지에서 학식, 셔틀, 핀으로 이동할 때 느리게 느껴지던 원인을 분석하고 홈 로드 성능 개선 기획을 작성했다.
- 홈 서버 로드에 패널별 로드 정책을 추가해 `셔틀`과 `핀` 진입 시 학식 메뉴 조회, 학식 평가 조회, 학식 DB 동기화를 기다리지 않게 했다.
- KV 캐시가 없는 개발 환경에서도 같은 주 학식 메뉴를 반복 크롤링하지 않도록 서버 메모리 캐시를 추가했다.
- 학식 메뉴 DB 동기화와 푸드코트 동기화를 화면 응답 이후 백그라운드 작업으로 넘겼다.

## 운영 메모

- `셔틀`과 `핀` 패널은 학식 데이터 없이도 먼저 열릴 수 있어야 한다.
- `학식` 패널은 메뉴 표시가 필요하므로 메뉴 조회를 유지하되, 반복 크롤링을 피하도록 캐시를 사용한다.
- 운영 환경에서는 Cloudflare KV가 우선 캐시 역할을 하고, 로컬 개발 환경에서는 서버 메모리 캐시가 보조 역할을 한다.
- 현재 개발 서버가 `.svelte-kit/cloudflare`를 점유한 상태에서는 `npm run build` 마지막 Cloudflare 어댑터 정리 단계에서 `EBUSY`가 날 수 있다.
