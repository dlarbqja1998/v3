# 서비스 정보 및 공공데이터 출처 화면 기획

## 목표

골라바유가 사용하는 외부 서비스와 공공데이터의 출처·이용조건을 한곳에서 확인할 수 있는 `서비스 정보` 화면을 제공한다. 메인 지도와 날씨 위젯에는 출처 문구를 노출하지 않되, 사용자가 앱 안에서 무리 없이 접근할 수 있는 경로를 유지한다.

## 진입 경로

- 마이페이지 최하단에 강조도가 낮은 텍스트 링크 `서비스 정보`를 둔다.
- `서비스 정보` 링크는 공개 경로 `/service-info`로 이동한다.
- `/service-info`는 로그인하지 않은 사용자도 직접 접근할 수 있어야 한다.
- 메인 지도, 날씨 위젯, 바텀시트와 하단 내비게이션에는 출처 문구나 별도 배지를 추가하지 않는다.
- 하단 내비게이션의 여섯 번째 고정 탭으로 만들지 않는다. 핵심 생활 기능의 탐색 구조를 흐리지 않으면서 마이페이지 안의 보조 메뉴로 제공한다.

## 화면 구조

### 상단

- 제목: `서비스 정보`
- 뒤로 가기 버튼
- Capacitor 앱에서는 Android 하드웨어 뒤로 가기와 iOS 화면 복귀 흐름을 지원한다.

### 데이터 출처

첫 구현에서는 기상청 날씨 데이터만 표시한다.

- 서비스명: `기상청 단기예보 조회서비스`
- 제공기관: `기상청`
- 이용조건: `공공누리 제1유형(출처표시)`
- 설명: `골라바유의 세종캠퍼스 날씨는 기상청 초단기실황·초단기예보 데이터를 가공해 제공합니다.`
- 원문 링크: `https://www.data.go.kr/data/15084084/openapi.do`
- 공공누리 링크: `https://www.kogl.or.kr/info/licenseType1.do`

온라인 환경에서는 원문 주소를 클릭 가능한 링크로 제공한다. Capacitor에서는 외부 브라우저로 열고, 일반 웹에서는 새 탭으로 연다. 외부 링크임을 접근성 이름으로 알린다.

## 표시 원칙

- 법적 고지를 숨김 처리하거나 화면 밖에 배치하지 않는다.
- 마이페이지의 핵심 계정 버튼보다 시각적 강조를 낮춘다.
- 글자 크기는 모바일 가독성을 해치지 않도록 최소 13px 이상으로 한다.
- `기상청이 골라바유를 후원한다`고 오해할 수 있는 문구나 로고 배치는 사용하지 않는다.
- 데이터의 정확성·지속 제공을 골라바유 또는 기상청이 보장한다고 표현하지 않는다.

## 데이터 확장 방식

향후 셔틀, 학식, 지도 등 외부 데이터 출처 표시가 필요해지면 같은 화면에 카드 또는 목록 항목으로 추가한다. 각 항목은 다음 공통 필드를 사용한다.

- 서비스명
- 제공기관
- 골라바유에서의 사용 목적
- 이용조건
- 원문 링크

## 제외 범위

- 메인 날씨 위젯 내부의 `기상청 제공` 문구
- 메인 화면의 출처 배지 또는 푸터
- 별도의 하단 내비게이션 탭
- 기상청 로고 사용
- 서비스 정보 화면에서 API 인증키·요청 URL·내부 캐시 구조 공개

## 검증 항목

1. 마이페이지에서 두 번 이내의 동작으로 기상청 출처를 확인할 수 있다.
2. 비로그인 사용자가 `/service-info`에 직접 접근할 수 있다.
3. 기상청 및 공공누리 링크가 올바른 HTTPS 주소로 열린다.
4. 메인 화면과 날씨 위젯에는 출처 문구가 추가되지 않는다.
5. 320px 폭에서도 문구와 링크가 잘리지 않는다.
6. Android·iOS 앱에서 외부 링크와 뒤로 가기가 정상 동작한다.

## 구현 시점

현재 날씨 API의 실제 운영 검증과 별개 작업으로 관리한다. 서비스 정보 화면 구현을 시작할 때 이 문서를 기준으로 별도 구현 계획과 테스트를 작성한다.
