# 메인 브랜드 아이콘 적용 기획

## 목적

크림슨 지도 핀 안에 호랑이 얼굴을 넣은 신규 아이콘을 메인 화면 좌상단 브랜드 영역에 시범 적용한다.

## 적용 범위

- 최종 투명 PNG를 `static/icon.png`에 저장한다.
- SvelteKit 정적 파일 경로인 `/icon.png`로 불러온다.
- 메인 화면 좌상단의 기존 44×44 크림슨 사각형과 지도 아이콘을 신규 이미지로 교체한다.
- 아이콘 오른쪽의 `골라바유` 제목과 로그인 영역은 유지한다.
- 별도의 클릭 동작은 추가하지 않는다.

## 화면 규칙

- 아이콘 표시 영역은 60×60px로 확대한다.
- 이미지 전체가 잘리지 않도록 `object-contain`을 사용한다.
- 기존 배경색과 내부 여백은 제거하고 투명 PNG 자체를 표시한다.
- 화면 상단 안전 영역과 기존 헤더 간격은 변경하지 않는다.

## 호환성

- `/icon.png`는 SvelteKit 웹과 Capacitor에 포함된 웹 화면에서 동일하게 제공한다.
- 외부 API나 브라우저 전용 기능은 사용하지 않는다.
- 로컬 Vite 개발 서버는 `0.0.0.0`에 바인딩해 `localhost`와 `127.0.0.1` 접속을 모두 지원한다.

## 검증

- 메인 화면에서 아이콘이 60×60px 안에 잘리지 않고 표시되는지 확인한다.
- `http://localhost:5173/`과 `http://127.0.0.1:5173/`이 모두 HTTP 200을 반환하는지 확인한다.
- `npm test`, `npm run check`를 실행한다.
- 프로덕션 빌드로 정적 파일 경로가 정상 처리되는지 확인한다.

## 제외 범위

- 파비콘, 앱 스토어 아이콘, 스플래시 이미지 교체
- 지도 장소 마커 교체
- 다른 화면의 공통 헤더 변경
