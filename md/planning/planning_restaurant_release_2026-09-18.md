# 교외 음식점과 지도 UI 운영 공개

## 공개 범위

사용자가 로컬에서 확인한 교내·교외 공통 필터, 지도 표현, 구역별 첫 진입 위치와 확대 단계, 음식점 상세 화면 및 캐시를 운영 사이트에 반영한다. 2026-09-18 사용자가 커밋·푸시·배포를 승인했다.

준비 완료 음식점은 840곳이며 고대앞 66곳, 욱일 186곳, 홍대사이 91곳, 조치원역 305곳, 신흥리 92곳, 죽림리 100곳이다. 식별 검토가 필요한 34개 항목은 공개하지 않는다. 확인된 KU멤버십은 교외 23곳과 교내 BBQ 1곳으로 총 24곳이다.

## 조회와 캐시

- 운영에서는 `places.is_visible`이 켜진 준비 완료 음식점과 `place_memberships.is_published`가 켜진 유효한 제휴만 읽는다.
- 개발 서버의 루프백 주소에서만 미공개 준비 자료를 검토할 수 있다. 운영·외부 주소의 상세 페이지와 미리 읽기 경로는 미공개 매장에 404를 반환한다.
- 서버 목록은 30초, 상세는 60초간 캐시하며 DB·공개/미리보기 모드·한국 날짜를 구분한다. 클라이언트 상세 캐시는 60초, 최대 80개다. 같은 자료의 진행 중 요청은 합치고 실패한 결과는 캐시에 남기지 않는다.
- 목록에서 상세를 열면 목록에 있는 기본 정보를 즉시 표시하고 상세를 이어서 읽는다. 지도 인스턴스와 목록 스크롤은 복귀 시 유지한다.

## 반영 절차

1. `npx tsx scripts/publish-restaurant-catalog.ts`로 준비 완료 원본 ID와 실제 DB의 일치 여부, 제휴 연결, 필요한 카테고리를 점검한다. 기본 실행은 조회만 한다.
2. 전체 테스트·타입 검사·프로덕션 빌드를 통과한 코드를 커밋하고 `origin/main`에 푸시한다.
3. 기존 Cloudflare Worker `v3`와 `golabau.com` 도메인에 배포한다.
4. `npx tsx scripts/publish-restaurant-catalog.ts --apply`로 해당 음식점·제휴·카테고리의 공개 플래그를 한 트랜잭션에서 켠다. 기존 내용이나 다른 장소의 공개 상태는 수정하지 않는다.
5. 운영 화면에서 구역과 목록 수, 음식점 상세, 여닫기, 전화 링크, 지도 연결을 확인한다.

공개 스크립트는 `output/restaurant-publication/`에 실행 전 공개 상태와 반영 후 수량을 기록한다. 재실행하면 이미 공개된 항목은 다시 수정하지 않는다. 실행 기록과 임시 검증 자료는 커밋하지 않는다.

## 배포 전 검증

- 전체 테스트: 124개 파일, 511개 테스트 통과.
- 타입 검사: 오류 0개, 경고 0개. Vite 클라이언트·서버와 Cloudflare 어댑터의 프로덕션 빌드 통과.
- 실제 DB의 공개 조회 0곳/미리보기 840곳, 공개 제휴 0곳/미리보기 24곳을 대조했다. 미공개 상세의 접근 차단과 공개·미리보기 캐시 분리도 확인했다.
- 공개 스크립트 사전 점검: 음식점 840곳, KU멤버십 24곳, `bar` 카테고리의 공개 변경 대상으로 확인됐다. 검토 보류 34개는 제외된다.

상세 UI와 서쪽 추가 수집 근거는 `planning_restaurant_detail_ui_2026-09-18.md`, `planning_restaurant_west_supplement_2026-09-18.md`에 기록했다. 두 문서의 로컬 전용 설명은 각 작업 당시 상태이며, 운영 공개 정책은 이 문서를 따른다.
