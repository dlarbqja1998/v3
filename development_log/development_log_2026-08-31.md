# 개발 로그 — 2026년 8월 31일

## 작업 목표

8월 28일 개발로그 이후 구현됐지만 기록되지 않은 셔틀 문구 수정과 오늘 행사 기능을 정리하고, 학식과 상시 식당의 역할을 분리해 메인 지도에서 모든 교내 식당을 탐색할 수 있도록 개선했다.

## 셔틀 방향 문구 정리

- 셔틀 페이지의 방향 선택 문구를 실제 이동 목적지가 바로 읽히도록 수정했다.
- `조치원역 방면`을 `조치원역 행`으로, `고려대 방면`을 `고려대 행`으로 변경했다.
- 화면과 도메인 테스트의 기대 문구를 함께 수정해 표기가 다시 어긋나지 않도록 했다.

## 오늘 행사 페이지와 상세 화면

- 하단 내비게이션의 `오늘`에서 현재 진행 중이거나 예정된 교내 행사를 확인할 수 있도록 목록 화면을 구현했다.
- 신청 기능보다 행사 홍보를 우선하는 방향으로 구성하고, 종료된 행사는 사용자 목록에서 숨기도록 했다.
- 행사 목록은 학식·셔틀과 같은 고정 헤더와 GB1 스타일의 목록·구분선 중심 위계를 사용했다.
- 행사 상세 화면에서 대표 이미지, 서브 이미지, 행사 기간, 위치, 설명을 확인할 수 있도록 했다.
- 등록된 행사가 없을 때 `예정된 행사가 없어요` 빈 상태를 표시하도록 했다.

## 관리자 행사 등록·수정·삭제

- 관리자 도구에 행사 관리 목록과 신규 등록, 수정 화면을 추가했다.
- 행사 제목, 카테고리, 기간, 장소명, 상세 설명과 노출 상태를 관리할 수 있도록 했다.
- 축제처럼 기존 시설 좌표에 묶이지 않는 행사를 위해 지도에서 임의 위치를 직접 지정하도록 구현했다.
- 행사 게시물을 삭제할 수 있도록 하고, 관리자 권한과 입력 검증을 서버에서 처리하도록 했다.
- 대표 이미지와 여러 서브 이미지를 업로드하고, 등록된 이미지 중 대표 이미지를 다시 지정할 수 있도록 했다.
- 행사 이미지는 Cloudflare R2의 `golabau-media` 버킷에 저장하고 DB에는 이미지 메타데이터와 표시 순서를 저장하도록 했다.

## 행사 지도 핀과 메인 탐색

- 전달받은 행사 핀 이미지를 지도용 SVG로 정리해 `static/images/map/event-pin.svg`로 저장했다.
- 메인 필터칩에서 `행사`를 가장 앞에 배치했다.
- 행사 필터를 선택하면 행사 핀이 지도에 나타나고, 선택된 행사가 지도 중심에 오도록 연결했다.
- 행사 바텀시트는 좌우 스와이프로 다음 행사를 탐색하고 상세 페이지로 이동할 수 있도록 했다.
- 학식·셔틀의 `지도에서 보기` 바텀시트도 같은 높이 체계와 좌우 탐색 흐름을 사용하도록 정리했다.
- 메인 기본 바텀시트는 접힌 상태에서 `지금, 고려대학교`와 날짜만 보여주고, 올렸을 때 지도를 직접 탐색하도록 안내하는 최소 구성으로 수정했다.

## 학식과 상시 식당 역할 분리

- 매주 식단이 바뀌는 `진리관 식당`, `교직원 식당`만 학식 페이지에 유지했다.
- 기존 정적 푸드코트 탭은 사용자 학식 화면에서 제거하고, 호환을 위해 필요한 기존 메뉴 데이터만 내부에 유지했다.
- `구시아 푸드마켓`, `bb.q CHICKEN`, `김밥전문점`은 관리자가 등록하는 상시 식당 시설 핀으로 분리했다.
- 시설 고정 카테고리에 `식당`을 추가하고 기존 `food` 아이콘을 사용하도록 했다.
- 메인 필터 순서를 `행사 → 식당 → 편의점 → 카페 → 서점 → 복사실 → 우체국 → 크림슨스토어 → 헬스장`으로 정리했다.

## 메인 식당 필터 탐색

- 식당 필터에서 관리자 등록 상시 식당 3곳과 진리관·교직원 식당을 함께 탐색하도록 했다.
- 기존 학식 호환 데이터 중 `restaurant` 카테고리가 아닌 항목은 식당 필터에서 제외했다.
- 식당을 포함한 시설 필터 결과는 접힌 높이가 아니라 중간 높이로 열어 설명과 연락처가 잘리지 않도록 했다.
- 행사 결과와 메인 최초 진입 바텀시트는 기존 접힌 높이를 유지했다.
- `/?panel=facility&category=restaurant` 딥링크로 식당 필터를 바로 열 수 있도록 홈 로드 정책을 확장했다.
- 시설 딥링크에서는 불필요한 학식 메뉴·평가 동기화를 기다리지 않고 지도 시설 데이터를 먼저 표시하도록 했다.

## 학식과 식당의 양방향 이동

- 학식 페이지 하단에 `다른 교내 식당 찾기`를 추가해 메인의 식당 필터로 이동하도록 했다.
- 메인 식당 결과 중 진리관·교직원 식당에만 `학식 페이지에서 보기`를 표시했다.
- 진리관은 `/cafeteria?cafeteria=jinri`, 교직원은 `/cafeteria?cafeteria=faculty`로 연결해 해당 학식 탭이 바로 선택되도록 했다.
- 상시 식당에는 학식 페이지 링크가 나타나지 않으며, 잘못된 식당 쿼리는 첫 번째 학식당으로 안전하게 돌아가도록 했다.
