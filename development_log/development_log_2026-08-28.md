- 잘못된 반복 횟수로 다시 회귀하지 않도록 인증 테스트를 보강했다.

## 관리자 핀 편집 UX 보완

- 저장된 핀을 선택할 때 같은 위치에 편집용 핀이 중복 생성되어 보이던 문제를 수정했다.
- 편집 중인 핀은 저장 핀 레이어에서 제외해 현재 이동 대상이 하나만 보이도록 했다.
- 핀 위치를 이동한 직후 저장 데이터가 다시 주입되어 원래 자리로 돌아가던 문제를 수정했다.
- 같은 핀을 편집하는 동안에는 최초 한 번만 저장값을 폼에 주입하고, 이후 사용자가 바꾼 좌표와 입력값을 유지하도록 했다.
- 수정사항이 있는 상태로 다른 페이지로 이동하면 이탈 확인 다이얼로그를 표시하도록 했다.
- 이탈 다이얼로그에서 `저장 후 나가기`, `저장하지 않고 나가기`, `계속 편집`을 선택할 수 있도록 했다.
- 저장 성공 후 원래 이동하려던 화면으로 이어지도록 폼 제출과 페이지 이동 흐름을 연결했다.

## 메인 지도 바텀시트와 NAVER 출처 표시

- 메인 바텀시트의 최소 높이를 160px에서 184px로 올려 첫 화면의 정보 노출량을 늘렸다.
- 최소 높이 변경에 맞춰 날씨 위젯의 하단 간격도 함께 계산하도록 수정했다.
- NAVER 출처 로고를 지도 오른쪽 하단으로 옮기고, 접힌 바텀시트와 날씨 위젯 사이에서 보이도록 위치 기준을 추가했다.
- 바텀시트를 올리면 NAVER 로고가 바텀시트 뒤로 가려지도록 지도 레이어의 쌓임 영역을 분리했다.
- 네이버 지도 SDK가 출처 로고를 늦게 생성하는 경우에도 `MutationObserver`로 감지해 같은 위치 규칙을 적용하도록 했다.
